# Support

`runtime-evidence` is in early development and does not yet provide production support guarantees.

- Use an issue for reproducible bugs and focused feature requests.
- Use a discussion for questions, ideas, and design conversations when discussions are enabled.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Please include the relevant operating system, Node.js version, project revision, configuration with secrets removed, and a minimal reproduction.
